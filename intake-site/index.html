חיבורים למערכות שלכם

הכול כאן לא חובה — מה שאין לכם עכשיו, נשלים יחד אחר כך.

🔒 למה בטוח למלא כאן מפתחות? כל מפתח או סיסמה שתמלאו בעמוד הזה נשמרים ישירות במסד נתונים מאובטח וייעודי, בערוץ מוצפן — הם לא נשלחים במייל ולא מופיעים בשום סיכום. גם לנו הם נגישים רק דרך הממשק המאובטח.

כדי שהמערכת תפיק חשבוניות וקבלות אוטומטית מול התוכנה שאתם כבר עובדים איתה.

איפה מוצאים את המפתחות בחשבונית ירוקה?
  1. נכנסים לחשבון בחשבונית ירוקה (greeninvoice.co.il).
  2. הגדרות (גלגל השיניים) ← חשבון ← לשונית API.
  3. לוחצים "הוספת מפתח" — ומעתיקים לכאן את ה-Key ואת ה-Secret (ה-Secret מוצג פעם אחת בלבד — העתיקו מיד).
איפה מוצאים את המפתח ב-EZcount?
  1. נכנסים לחשבון EZcount.
  2. הגדרות ← הגדרות API (או "פיתוח / API").
  3. מייצרים / מעתיקים את ה-API Key ומדביקים כאן.
אם אתם לא מוצאים — כתבו בהערות בסוף ונעזור.
פרטי התחברות ל-iCount: נצטרך את מזהה החברה (Company ID) ושם המשתמש שאיתם נכנסים ל-iCount, וסיסמה או API Token (אם יש לכם — הגדרות ← API).

כל מה שתכתבו כאן נשמר במסד המאובטח בלבד.

המערכת שולחת ללקוחות שלכם דיוור, גזירי מודעות וחשבוניות במייל. מאיזו כתובת לשלוח?

איך מייצרים סיסמה לאפליקציות ב-Gmail? (לוקח דקה)
  1. נכנסים ל-myaccount.google.com מהחשבון של מייל המערכת (זה שמילאתם למעלה — חשוב שזה אותו חשבון!).
  2. בתפריט: אבטחה ← מוודאים שאימות דו-שלבי פעיל (אם לא — מפעילים).
  3. מחפשים בחיפוש למעלה "סיסמאות לאפליקציות" (App passwords) ← יוצרים סיסמה חדשה (שם חופשי, למשל "מערכת העיתון").
  4. מעתיקים את 16 התווים לכאן — בלי רווחים.

אם אתם גובים מלקוחות בכרטיס אשראי — עם איזה ספק סליקה אתם עובדים?

לא בטוחים איפה זה? אין לחץ — אפשר לסמן את הספק ולהשלים את הפרטים אחר כך יחד עם חיים.

מרכזיה / טלפוניה, מערכת דיוור, או כל מערכת אחרת שהעיתון עובד איתה וכדאי שנכיר.

משהו בשדות שמולאו לא תקין — בדקו את הסימונים באדום.
